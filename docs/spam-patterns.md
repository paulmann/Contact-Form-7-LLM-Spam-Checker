# Банк паттернов keyword-фильтра (Spam Checker Pro for Contact Form 7)

**Назначение.** Рабочий банк лексики для keyword-фильтра плагина (Settings →
Protection → Keyword blacklist). Файл — источник данных для настройки плагина и для
тестов механизма. В релизный ZIP плагина он не входит (см. `tools/build-release.sh`).

**Кто наполняет.** Банк пополняет владелец проекта отдельным процессом (с ревью).
Разработчик/агент **не придумывает и не добавляет паттерны самостоятельно** — его зона:
механизм сопоставления, нормализация списка, тесты механизма на токенах из этого файла.

**Как паттерны попадают в плагин.** Скопировать нужные строки в поле «Keyword blacklist»
на странице Settings → Protection (значения с новой строки или через запятую).
Дефолтный список — `Settings::DEFAULTS` → `checks.keyword_spam.keywords`.

**Семантика сопоставления.** Регистронезависимый поиск подстроки в тексте сообщения;
многословные фразы поддерживаются; список парсится из переносов строк и запятых
(`KeywordSpamCheck::parseList()`). Рекомендации к токенам:

- нижний регистр, один токен на строку;
- длина от 4 символов — короткие дают ложные срабатывания;
- фразы лучше одиночных слов («payday loan» точнее «loan»);
- избегать чрезмерно общих слов — см. раздел «Не добавлять».

## Стартовый набор (лёгкие примеры)

### Крипто-рассылки
`crypto`, `bitcoin`, `ethereum`, `airdrop`, `token presale`, `wallet recovery`,
`криптовалюта`, `биткоин`, `аирдроп`

### «Быстрый заработок»
`guaranteed income`, `earn from home`, `fast money`, `passive income online`,
`быстрый заработок`, `заработок без вложений`, `пассивный доход`, `доход от 100000`

### Финансовые офферы
`payday loan`, `personal loan approval`, `instant loan approval`,
`займ без отказа`, `микрозайм онлайн`

### Азартные игры
`casino`, `lottery`, `jackpot`, `free spins`, `slots online`, `ставки на спорт`,
`букмекерская контора`

### Фарма
`viagra`, `cialis`, `pharmacy`, `no prescription`, `без рецепта`, `онлайн-аптека`

### SEO-спам
`seo services`, `backlinks`, `guest post outreach`, `link building`,
`наращивание ссылочной массы`, `гостевые посты`

### Розыгрыши и «выигрыши»
`you have won`, `congratulations you have been selected`, `claim your prize`,
`вы выиграли`, `поздравляем вы победитель`, `заберите приз`

## Не добавлять (ложные срабатывания)

`free`, `money`, `win`, `gift`, `offer`, `работа`, `деньги`, `выигрыш`, `кредит`,
`заработок` — одиночные частотные слова будут срабатывать на легитимные сообщения.
Правило: токен — специфичная фраза, а не частотное слово.

## Связь с кодом

| Что | Где |
|---|---|
| Парсинг списка (переносы + запятые) | `KeywordSpamCheck::parseList()` |
| Сопоставление (регистронезависимый substring) | `KeywordSpamCheck::run()` |
| Дефолтный список | `Settings::DEFAULTS` → `checks.keyword_spam.keywords` |
| Совпавший токен | попадает в `reasons` события реестра (поле `keyword`) |
| Тесты механизма | `tests/smoke.php` — только на токенах из этого файла или синтетических безобидных строках |
